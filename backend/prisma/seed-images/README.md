# Fotos padrão dos produtos de teste

Coloque aqui uma foto para cada produto criado pelo seed. Ao rodar `npm run prisma:seed`, cada foto é
copiada para a pasta de uploads (`backend/uploads`) e vinculada ao produto. Produtos sem foto continuam
sem imagem, e uma foto que o vendedor já tenha enviado pelo app não é substituída.

## Requisitos

- Formato JPEG, PNG ou WebP (o conteúdo é conferido, não só a extensão).
- No máximo 5 MB (RNF05); o ideal é ficar abaixo de 300 KB.
- Proporção 4:3, em paisagem. Sugestão: 1200 x 900 px.
- O produto centralizado: a vitrine mostra a foto pequena e quadrada, cortando as laterais.
- Use fotos próprias ou com licença livre (Unsplash, Pexels), que podem ser usadas no trabalho.

## Nomes dos arquivos

O nome é o nome do produto em minúsculas, sem acentos e com hífens. Também vale `.jpeg`, `.png` ou `.webp`.
